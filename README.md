# Form-dos-Caes

## Sobre o Projeto

Este projeto consiste em um sistema de formulário web voltado para a intenção de adoção de cachorros. A aplicação foi desenvolvida com foco na estruturação e estilização de formulários interativos, garantindo uma experiência de usuário agradável e organizada para coletar dados essenciais de potenciais adotantes.

O projeto é composto por uma página principal contendo o formulário (`index.html`), uma página dedicada aos termos e condições de adoção (`termos.html`), e uma folha de estilos unificada (`style.css`) que gerencia a identidade visual do site.

---

## Funcionalidades

* Formulário completo com diferentes tipos de campos para coleta de informações dos adotantes.
* Página exclusiva para leitura e aceite dos termos e responsabilidades de adoção (`termos.html`).
* Navegação entre a página do formulário e a página de termos.
* Estilização personalizada de inputs, botões, caixas de seleção e layouts de formulários com CSS.
* Interface responsiva e amigável, temática para o universo pet.

---

## Tecnologias Utilizadas

* **HTML5**
* **CSS3**

---

## Objetivo

O principal objetivo deste projeto é praticar a criação, validação visual e estruturação de formulários complexos em HTML, além de trabalhar com a navegação entre múltiplas páginas e manter a consistência visual usando o mesmo arquivo de estilo.

---

## Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos como:

* Utilização de diversas tags e atributos de formulário em HTML (labels, inputs, textareas, etc.).
* Vinculação e navegação entre diferentes arquivos HTML no mesmo domínio.
* Estilização avançada de elementos de formulário com CSS (estados de foco, desabilitado, alinhamentos).
* Organização estrutural e semântica para garantir a acessibilidade básica do formulário.
* Boas práticas de design de interface voltadas para a experiência do usuário (UX).

## Como Executar

1. Clone este repositório:
```bash
git clone [https://github.com/seu-usuario/Form-dos-Caes.git](https://github.com/seu-usuario/Form-dos-Caes.git)
```

2. Acesse a pasta do projeto:

```bash

```

3. Abra o arquivo index.html em seu navegador de preferência para acessar o formulário de adoção.
